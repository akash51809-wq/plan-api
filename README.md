# Easy Recharge Solution — 3D Website

A fresh, original, responsive landing page for **Easy Recharge Solution**.

## Included
- 3D animated API command-center hero
- Glassmorphism panels and floating API nodes
- Scroll reveal animations
- Animated request/response visual
- Responsive mobile + desktop layout
- Partner Login button linked to `https://plan.easyrechargesolution.com`
- Contact details for Prince Goyal / Prayagraj
- No copied competitor branding, copy, images, or layout

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deployment
This is a static site and can be deployed to GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any static hosting service.
